# VaultKit

**Профессиональный инструмент для локального шифрования файлов и директорий.**

Работает полностью в браузере. Данные не покидают ваше устройство. AES-256-GCM, 120,000 итераций PBKDF2.

---

## Возможности

- **Шифрование файлов и целых папок** с сохранением структуры
- **Пакетная обработка** — десятки тысяч файлов за раз
- **Drag & Drop** — перетащили папку, получили `.vault`
- **Сжатие перед шифрованием** — экономит место
- **Генератор криптостойких паролей**
- **Индикатор сложности пароля**
- **История операций** с сохранением в localStorage
- **AES-256-GCM** с солью и вектором инициализации
- **120,000 итераций PBKDF2** (защита от брутфорса)
